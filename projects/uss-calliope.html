Unity · C# · Gameplay Systems

USS Calliope

An isometric team prototype featuring a custom-built, data-driven weapon pipeline and dynamic accuracy mechanics.

  • Unity
  • C#
  • Input System
  • ScriptableObjects
  • Cinemachine

Project Overview

  • Role: Gameplay Programmer (Owned player combat end-to-end)
  • Team & Timeline: 5 Developers · 1-week sprints · 8 weeks
  • Engine: Unity

Architecture & Core Features

  • Decoupled Combat Pipeline: Programmed a highly modular attack sequence framework separating concerns between the player's core AttackInput driver, target aiming, weapon handlers, and a specialized ImpactProcessor backend.
  • Data-Driven Weapons: Engineered a robust SO_WeaponType architecture utilizing ScriptableObjects to cleanly abstract unique gun behaviors including hitscan vs. projectile logic, ammunition properties, and custom damage-falloff curves.
  • Dynamic Accuracy Scoring: Authored a real-time hit-chance algorithm that calculates systemic variables (distance, active stamina, current health, and motion) to dynamically scale screen-space crosshair size, color indicators, and procedural weapon spread.
  • Memory & Pipeline Tooling: Developed a high-performance AudioPoolManager to handle dynamic weapon impacts and step audio cleanly, alongside a custom Unity editor asset tool to enforce unique structural GUIDs across ScriptableObject databases.

BallisticsUtility.cs — Box-Muller Gaussian Spread Transformation
public static Vector3 GetGaussianSpread(Vector3 forward, float spreadStandardDeviation)
{
    var u1 = Random.value;
    var u2 = Random.value;
    var offsetX = Mathf.Sqrt(-2f * Mathf.Log(u1)) * Mathf.Cos(2f * Mathf.PI * u2);
    var offsetY = Mathf.Sqrt(-2f * Mathf.Log(u1)) * Mathf.Sin(2f * Mathf.PI * u2);
    offsetX *= spreadStandardDeviation;
    offsetY *= spreadStandardDeviation;

    var right = Vector3.Cross(Vector3.up, forward.normalized);
    var up = Vector3.Cross(forward, right).normalized;
    return (forward + offsetX * right + offsetY * up).normalized;
}
