  • Stack Vulkan 1.3 · Win32 API · C++20 · VMA · GLM

Contributions & Architecture

  • Decoupled Subsystems: Designed a structured core layer splitting ownership cleanly between the application driver (Engine), native window management, graphics contexts, and the renderer.
  • Native Win32 Window Layer (WIP): Developing a custom windowing layer directly on the native **Win32 API**, eliminating third-party wrapper dependencies to maintain low-overhead setup and custom message processing.
  • Context Management: Implemented a dedicated VulkanContext abstraction to encapsulate physical/logical device selection, extensions validation, instance lifetime, and surface bindings.
  • Pipeline Abstraction: Created a highly reusable PipelineBuilder module to streamline complex Vulkan graphics and compute pipeline configuration.

void Win32Window::PollEvents() 
{
    MSG msg = {};
    while (PeekMessage(&msg, nullptr, 0, 0, PM_REMOVE)) 
    {
        TranslateMessage(&msg);
        DispatchMessage(&msg);
        
        if (msg.message == WM_QUIT) 
        {
            m_ShouldClose = true;
        }
    }
}
