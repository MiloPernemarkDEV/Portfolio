MelonEngine

A modular Vulkan 1.3 graphics engine written from scratch in modern C++ featuring custom native platform layers.

Project Overview

  • Role: Engine Programmer (Solo)
  • Status: Active Development (Win32 Backend WIP)
  • Stack: Vulkan 1.3 · Win32 API · C++20 · VMA · GLM

Architecture & Core Features

  • Decoupled Subsystems: Programmed a modular core architecture that cleanly separates explicit ownership boundaries between the primary driver (Engine), native window wrappers, device contexts, and the renderer backend.
  • Native Win32 Window Layer: Developing a lightweight, zero-dependency windowing wrapper using the native **Win32 API** to manage window lifecycles and handle raw OS hardware message pumps directly.
  • Context Management: Implemented a detailed VulkanContext abstraction to encapsulate physical/logical device selection, extension verification, validation layers, and surface bindings.
  • Pipeline Abstraction: Created a highly reusable, fluid PipelineBuilder class to streamline complex Vulkan graphics and compute pipeline configuration, layout tracking, and shader stage compilation.

    m_VulkanContext = std::make_unique<VulkanContext>(*m_Window);
    m_Renderer = std::make_unique<VulkanRenderer>(*m_VulkanContext, *m_Window);

}
Win32Window.cpp (WIP Backend) — Message Dispatch Pump
void Win32Window::PollEvents() 
{
    MSG msg = {};
    while (PeekMessage(&msg, nullptr, 0, 0, PM_REMOVE)) 
    {
        TranslateMessage(&msg);
        DispatchMessage(&msg);
        
        if (msg.message == WM_QUIT) 
        {
            m_ShouldClose = true;
        }
    }
}
