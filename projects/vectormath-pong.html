C++ · Unity · Native Interop

VectorAssignment & Pong

A native C++ vector mathematics library compiled into a custom dynamic-link library and integrated into Unity using high-performance P/Invoke marshaling.

  • C++
  • Unity
  • P/Invoke Interop
  • Data Marshaling

GitHub Repository (opens in new tab)

Project Overview

  • Role: Engine & Interop Programmer (Solo)
  • Scope: Native C++ DLL development, isolated unit test frameworks, and a Unity-managed client architecture.
  • Stack: C++ · Unity (C#) · Platform Invoke (P/Invoke)

Architecture & Core Features

  • Native Math Library Generation: Developed an optimized C++ mathematical core exporting specialized 2D and 3D vector routines through a clean C-compatible dynamic link library (VectorAssignment.dll).
  • Isolated Testing Suite: Programmed a standalone command-line testing runner (TestOperations) to comprehensively validate vector logic, bounds handling, and geometric projections completely isolated from engine runtimes.
  • Cross-Language Data Marshaling: Implemented a secure managed/unmanaged bridge using explicit C# sequential structural layout definitions (StructLayout) and signature mappings to handle direct memory transfer without overhead.
  • Custom Physics Simulation: Built a custom 2D gameplay sandbox simulation where all physics state transformations, surface collisions, and linear vector calculations are delegated purely to the native backend via the interop bridge rather than default engine tools.

Code Samples

Vector Math — Ray Reflection Geometry (C++)
Vec2 v2_reflect(Vec2 v, Vec2 normal) {
    float dot = v2_dot(v, normal);
    Vec2 scaledNormal = v2_scale(normal, 2.0f * dot);
    return v2_subtract(v, scaledNormal);
}
PongVector.cs — P/Invoke Interop Layout Definitions
[StructLayout(LayoutKind.Sequential)]
public struct Vec2 {
    public float x;
    public float y;
}

[DllImport("VectorAssignment")]
public static extern Vec2 v2_add(Vec2 a, Vec2 b);

[DllImport("VectorAssignment")]
public static extern Vec2 v2_reflect(Vec2 v, Vec2 normal);
