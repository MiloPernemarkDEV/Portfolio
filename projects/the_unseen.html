Project Overview

  • Role: Gameplay & Systems Programmer
  • Status: Completed Feature Set
  • Stack: Unreal Engine C++ · Variadic Templates · Custom Event Routing

Architecture & Core Features

  • Decoupled Puzzle Architecture: Programmed a flexible, modular puzzle system splitting responsibility across four discrete actors (Board, Node, Link, and Listener), allowing designers to build infinitely custom puzzle layouts directly within the editor viewport.
  • Sequence Validation: Implemented a clean sequence tracking system within the controller board actor that records exact player inputs and verifies order-dependent puzzle logic before executing state updates.
  • Blueprint-Safe Event Dispatching: Developed specialized event listener components that convert low-level C++ triggers into dynamic Blueprint events via dynamic multicast delegates, allowing gameplay reactions without tight code-to-asset coupling.
  • Zero-Overhead Debug Utilities: Engineered a type-safe `DebugUtility` tool using C++ variadic templates that auto-resolves engine strings (FText, FName) at compile time and strips completely out of shipping builds (UE_BUILD_SHIPPING).

DebugUtility.h — Type-Safe Variadic Screen Messaging Template
template <typename... Args>
static void ScreenMessage(const FString& Format, Args&&... args)
{
#if !UE_BUILD_SHIPPING
    // Type-safe structural conversion and argument forwarding at compile time
    FString FormattedMsg = FString::Printf(*Format, ToLogString(std::forward<Args>(args))...);
    
    if (GEngine)
    {
        GEngine->AddOnScreenDebugMessage(-1, 5.f, FColor::Cyan, FormattedMsg);
    }
    UE_LOG(LogTemp, Log, TEXT("%s"), *FormattedMsg);
#endif
}
ABoardPuzzleNode.cpp — Evaluation Logic Flow
void ABoardPuzzleNode::OnPlayerInteract()
{
    if (bIsLocked || !m_AssociatedLink) return;

    // Advance puzzle chain state and register with controller board
    m_AssociatedLink->UnlockLink();
    
    if (m_ParentBoard)
    {
        m_ParentBoard->RegisterLinkActivation(m_AssociatedLink->GetLinkID());
        
        if (bIsEndingNode)
        {
            m_ParentBoard->ValidatePuzzleSolution();
        }
    }
}
