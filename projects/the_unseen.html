Contributions & Architecture

  • Decoupled Board Puzzle System: Architected a single-responsibility, node-based interaction sequence manager utilizing four dedicated actors (Board, Node, Link, and Listener) to allow designers to build infinitely reusable layout permutations entirely in-editor.
  • State & Order Validation: Programmed a standalone tracking matrix inside the board actor that records exact player activation patterns, verifying order-dependent logic sequences before firing state changes.
  • Blueprint-Safe Event Dispatching: Developed specialized event listener actors translating low-level C++ triggers into dynamic Blueprint events, creating direct gameplay reaction capabilities with zero hard dependency coupling.
  • Zero-Overhead Metaprogramming Utilities: Engineered DebugUtility, a type-safe logging suite using C++ variadic templates that auto-resolves engine data transformations (FText, FName) at compile time and strips completely out of shipping configurations via compiler expansion (UE_BUILD_SHIPPING).

DebugUtility.h — Type-Safe Variadic Screen Messaging Template
template <typename... Args>
static void ScreenMessage(const FString& Format, Args&&... args)
{
#if !UE_BUILD_SHIPPING
    // Type-safe structural conversion and argument forwarding at compile time
    FString FormattedMsg = FString::Printf(*Format, ToLogString(std::forward<Args>(args))...);
    
    if (GEngine)
    {
        GEngine->AddOnScreenDebugMessage(-1, 5.f, FColor::Cyan, FormattedMsg);
    }
    UE_LOG(LogTemp, Log, TEXT("%s"), *FormattedMsg);
#endif
}
ABoardPuzzleNode.cpp — Evaluation Logic Flow
void ABoardPuzzleNode::OnPlayerInteract()
{
    if (bIsLocked || !m_AssociatedLink) return;

    // Advance puzzle chain state and register with controller board
    m_AssociatedLink->UnlockLink();
    
    if (m_ParentBoard)
    {
        m_ParentBoard->RegisterLinkActivation(m_AssociatedLink->GetLinkID());
        
        if (bIsEndingNode)
        {
            m_ParentBoard->ValidatePuzzleSolution();
        }
    }
}
