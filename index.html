C++ PROJECT

Melon Engine

A native, modular Vulkan 1.3 graphics engine written from scratch in C++. The purpose of this project is to learn how low-level subsystems manage hardware context selections, compile pipeline interfaces, and process operating system boundaries cleanly.

  • Win32 Window Layer (WIP): Engineering a custom, low-overhead native platform window backend wrapper to handle window mutations and raw hardware event message pumps directly.
  • Pipeline Abstraction: Created a highly reusable `PipelineBuilder` class to streamline complex Vulkan graphics and compute pipeline configuration, shader stages, and layout compilation.
  • Subsystem Decoupling: Architected a structured core architecture splitting ownership cleanly between the core application layer (`Engine`), window controllers, and the backend `VulkanRenderer`.

NATIVE INTEROP
C++ / C# / Native Plugins

Native Math Library & Pong Clone

A technical exercise in cross-language communication, consisting of a custom 2D math library written in unmanaged C++ that runs a simple Pong simulation inside Unity via DLL plugins.

Technical Focus:

  • P/Invoke Integration: Used `DllImport` to expose raw C++ structure math functions directly to Unity's managed C# environment.
  • Memory Layouts: Applied strict `LayoutKind.Sequential` structures to ensure that data packages retained the same memory size and alignment across language barriers.
  • Physics Calculations: Calculated basic directional reflection vectors and continuous AABB collision boundaries entirely inside the C++ DLL.
